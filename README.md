## 👤 Author
Vinay Arjariya

---

## 🚀 Overview
This project is an AI-powered talent scouting agent that helps recruiters automatically analyze job descriptions, match candidates, and generate a ranked shortlist.

---

## 🧠 Features
- Extracts key skills using Gemini AI
- Matches candidates based on skills and experience
- Simulates candidate interest
- Generates ranked shortlist
- Provides explainability

---

## ⚙️ How It Works
1. Input Job Description
2. Gemini extracts skills
3. Match candidates
4. Simulate interest
5. Rank candidates

---

## 📊 Scoring Logic
- Match Score → Skills + Experience  
- Interest Score → AI-generated  
- Final Score → (0.6 × Match) + (0.4 × Interest)
